# Proyecto_FullStackII
Proyecto E.F N°1 de asignatura FullStack II

en este proyecto se incluira el FrontEnd y una continuacion del proyecto de FullStack I, el cual consistia en el BackEnd de microservicios, en el cual se implementa HTML, CSS y JS para incluir vista a lo que es el proyecto

CSS: se utilizo para crear estilos y detalles para la pagina, al igual que se utilizaron fuentes de escritura alternas a la que viene por predeterminado
JS: se utilizo para crear objetos y funciones que permitan la validacion de objetos en base a un formulario ademas de funciones para procesar y limpiar los errores con botones
HTML: se utilizo para darle cuerpo a la pagina web y diseñar como debe ir cada cosa, ya sea una imagen, formulario gracias a los div
